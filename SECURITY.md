# Security Policy

## Supported Versions

Only the latest release on the `main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

Please report security issues **privately**. Do **not** open public GitHub issues for security problems.

**Preferred contact method:**
- Open a private security advisory via GitHub: https://github.com/jabrahns-source/Q-Reg/security/advisories/new
- Or contact the maintainer (Jacarri Sanders / jabrahns-source) via GitHub private message or the repository discussions (security-labeled only).

We will acknowledge reports within 72 hours and provide a timeline for remediation based on severity.

# Building & Running Q-Reg

## Prerequisites

- Python 3.10+ (3.11, 3.12 tested)
- Git
- pip

## One-command local verification (recommended)

```bash
git clone https://github.com/jabrahns-source/Q-Reg.git
cd Q-Reg
make install
make verify-all
```

This runs the deterministic demo, the 9-vector adversarial suite, Z3 formal checks, and full cryptographic verification of the resulting ledger (Merkle + Ed25519). It mirrors the GitHub Actions path.

## Option 2: Local Installation (manual)

```bash
git clone https://github.com/jabrahns-source/Q-Reg.git
cd Q-Reg

python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

pip install -r requirements.txt

# Deterministic demo
python qreg_engine.py --demo

# Tests
pytest test_vectors.py -v

# Formal (Z3)
python verification/verify_gate_logic.py

# Crypto verification (hard-fails on Merkle mismatch)
python kerna_verify.py --ledger ledger.jsonl --check-merkle --validate-signatures
```

## Option 3: Docker

```bash
git clone https://github.com/jabrahns-source/Q-Reg.git
cd Q-Reg

docker build -t qreg .
docker run --rm qreg python qreg_engine.py --demo
```

## CI/CD

On push to `main` / `develop`, GitHub Actions:

- Runs tests on Python 3.10, 3.11, 3.12
- Executes Z3 gate-logic verification
- Generates a deterministic demo ledger
- Checks Merkle root consistency (hard fail)
- Validates every Ed25519 signature
- Uploads coverage + ledger artifacts

See `.github/workflows/ci.yml`.

## Troubleshooting

**ImportError: No module named 'qreg_engine'**  
Run from the repository root and ensure the virtualenv is active.

**Merkle root mismatch**  
`kerna_verify.py --check-merkle` now exits non-zero on mismatch. Re-run the demo with the deterministic flag (default in CI and `make demo`) and compare.

**Z3 not found**  
`pip install z3-solver` (already listed in `requirements.txt`).
